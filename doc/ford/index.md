## Key Features

- **GW Approximation** - Quasiparticle corrections
- **Bethe-Salpeter Equation** - Excitonic effects
- **Real-Time Dynamics** - Non-linear responses
- **Electron-Phonon Coupling** - Transport properties
- **Parallel & GPU** - High-performance computing
