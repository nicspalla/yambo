C***BEGIN PROLOGUE  DBESJ0
C***PURPOSE  Compute the Bessel function of the first kind of order

C***DESCRIPTION

C                                        with weighted error   4.39E-32
C                                         log weighted error  31.36
C                               significant figures required  31.21
